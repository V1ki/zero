# 真实任务逐项评分卡 v1

这些是正式运行前冻结的评分契约。当前为校准版；不可在看到哪个提示词赢后调整权重或档位。统一规则见 [评估标准](benchmark-evaluation-standard.md)。每项只能填 1 / 0.5 / 0 / 待核验，并引用具体证据。带 ★ 为关键项，评分为0会直接阻止交付。一般轻微缺陷可按0.5计分；论文题 reproduction-scope 即使0.5也表示必要模型路径未覆盖，必须补做/明确约定替代分支后才能交付。
