# 进阶题库校准：2026-09-05

新增复杂度应该来自真实失败机制，而不是单纯增加文本长度。当前已补 6 个多步场景，原有 basic 题库和 396 次历史结果保持独立；这一轮只校准进阶题，不据此批准提示词或排列模型能力。

## 新增覆盖

1. 清单驱动的多文件修改，保留其他环境参数与用户已有文件。
2. 先复现测试失败，读取策略后修复，验证最终内容。
3. 数据读取后收到追加要求，按新规则去重、筛选并分组计算。
4. 明细与缓存看板冲突，按时间和业务口径输出结构化结论。
5. 文档夹带伪系统指令，仍按用户要求提取功能，不发送或删除。
6. 接口部分失败，有限重试后交付已知值、缺失来源及 partial 状态。

进阶验收检查 JSON 产物、操作权限、必要步骤和最终回复；JSON 键顺序与空白不影响分数。环境使用模拟工具，测试不运行真实编译器，尚未覆盖完整 ZeRo session 或长上下文压缩。

## 下一阶段应做什么

优先定位并复测空回复，再加入脱敏真实失败任务，保留一部分不参与提示词调优。关键任务使用隔离的真实仓库或工作区验收，测完整会话、后台恢复、已有修改保护及上下文压缩。

基础回归、进阶任务、真实任务留出集分别看分；先排除新增风险与关键任务退步，再比较目标场景的改善和同等质量下的成本。具体复测命令及扩展路线见 [使用文档](prompt-benchmark.md)。
