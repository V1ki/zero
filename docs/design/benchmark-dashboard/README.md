# Benchmark Web 看板设计 v1

2026-09-06。独立、只读交互原型；尚未接入 ZeRo Web 路由、后端或评审服务。

## 目标与信息结构

使用者应能回答：候选是否改善交付、哪些任务退步、执行和评审消耗多少、结论依据是什么。首屏默认版本对照，先展示机械验收的改善/退步/持平/不可比，再看消耗，不以 token 减少替代质量判断。

| 页面 | 核心内容 | 主要动作 |
| --- | --- | --- |
| 实验记录 | 批次、来源、环境、执行数量、机械验收与独立评审状态 | 进入批次对照 |
| 版本对照 | 冻结版本、任务范围、模型筛选、配对结论、模型消耗、计量完整性、任务明细 | 筛选退步、查看单次证据 |
| 任务与标准 | 任务专属标准、权重、关键项、满分/部分/失败、所需证据 | 切换任务、展开标准 |
| 评审工作台 | 证据准备、盲评、分歧复核 | 本版仅展示待实现流程 |
| 执行详情抽屉 | 基线/候选切换、模型与工具过程、机械验收、证据索引 | 从结论追到操作及证据 |

桌面采用左侧导航、主区宽表、右侧详情抽屉。小屏导航移至顶部，图表纵向排列，明细表局部横向滚动。沿用 ZeRo 深色背景与青色主色；红色只表示退步/失败，琥珀色表示待判断或限制。未知不渲染为绿色通过或数字 0。

## 数据与比较约定

- 原型使用原生接入验证 12 次记录和历史试验 36 次记录；仅在各自批次内配对，不跨批次归因。前者主任务 3 对持平，后者主任务 1 对退步、11 对持平。
- 默认主任务；收尾判断单独筛选。范围与“只看退步”同时作用于计数、图表、消耗与明细，页面注明当前分母。
- 当前每组合只有一次重复。持平仅指机械验收结果相同；不能推出质量等价、稳定性或显著改善。
- 当前都是实际模型、模拟工具。未来离线/受控/真实环境必须显式标记，不混成总榜。
- 未缓存输入、缓存读取、缓存写入、输出分别保存；推理 token 属于输出子集，不重复加总。原型主图呈现输入/输出/调用/耗时，后续详情补齐全部计量字段。
- 执行和评审分开计量。模型费用未知时不得显示总费用为 0；实际账单、估算、声明免费按币种与依据分别展示，不隐式汇率换算。
- 历史无逐步事件时展示可用汇总和缺失说明；不能推导为零调用。指纹只证明内容身份，不证明参数合理或产物正确。
- 14 个任务、75 条质量标准来自现有标准库，状态仍为待校准，未用于上面记录的自动质量打分。论文研究、复现、配图、公众号草稿与审核可在标准页查看。

## 后续产品接入边界

第一阶段接入只读查询，不添加启动运行按钮。建议路由为 `/benchmarks`、`/benchmarks/runs/:runId`、`/benchmarks/compare`、`/benchmarks/tasks` 和 `/benchmarks/reviews`。它们是设计建议，目前不存在这些功能接口。

建议后端提供批次索引、批次摘要、平台对照结果、试验详情、证据索引和标准版本查询。复用平台现有比较与汇总逻辑，前端不另写结论引擎。批次使用稳定 ID，不把文件路径当公共 API 参数。相同案例/目标/环境/比较键/区组/重复才可配对；重复键拒绝、缺失或漂移显示不可比，并解释原因。

运行状态需要可信心跳或执行状态接口；缺少完成文件不能推断为运行中。加载、空列表、请求失败、部分记录、缺失用量、不可比均有独立状态，禁止请求失败后显示空的成功看板。过滤条件应进入 URL，便于分享与刷新恢复。

证据接口在允许目录内按 ID 解析并验证，预览默认脱敏。展示工具名、参数结构差异、输入输出指纹、重试/错误、实际模型及产物版本；完整正文按需加载。HTML 等产物采用隔离预览，不能直接作为活动页面执行。评审结论绑定不可变产物哈希与标准版本。

第二阶段才增加独立盲评与人工复核：隐藏模型和版本，逐项填写结果、引用证据、保留无法判断；未完成的评分只显示已覆盖权重与缺口，不显示伪完整总分。记录评审模型/提示词/标准版本、用量与分歧处理历史。

第三阶段增加多次重复、环境波动与模型×提示词对照。固定输入和工具快照的对照与真实环境重复运行分开展示；提供配对分布、区间、样本数，不能用单次耗时给出稳定效率排名。

## 原型文件与使用

- `index.html`、`style.css`、`app.js`：页面与交互。
- `data.js`：白名单元数据快照。仅保留指标、机械检查、操作元数据、指纹和标准；没有原始消息、工具参数/结果正文、证据文件路径。
- 本地打开 `index.html` 即可；本次预览地址为 `http://127.0.0.1:9395/index.html`，仅服务此设计目录。

数据源：`.zero/benchmarks/prompt-native-smoke-20260906/platform/results.jsonl`、`.zero/benchmarks/platform-v1-20260906/prompt-final/results.jsonl` 和 `benchmarks/zero-runtime/fixtures/prompt-bench/evaluation-rubrics-v1.json`。没有修改原始运行记录，没有重跑模型。

## 验证

脚本通过 Bun 浏览器构建检查。浏览器已核对真实记录的筛选分母、历史退步定位、历史缺失轨迹提示、产物检查失败与证据索引。原型不代表生产 API、评审写入或实时状态已通过验收。
